# Paw Place 🐾

A dog daycare management portal built with React and TypeScript.
Staff can log in and manage dogs with full CRUD functionality.

🔗 **[View live demo](https://dog-portal.netlify.app/)**

**Login credentials:**
- Username: `admin`
- Password: `password`

## Features

- 🔐 Login with protected routes
- 📋 List all dogs
- ➕ Add new dogs
- ✏️ Edit dog details
- 🗑️ Delete dogs
- ✅ Mark dogs as arrived
- 🔀 Client-side routing with React Router

## Tech Stack

- React
- TypeScript
- React Router DOM
- useContext for global state management
- CSS

## Getting Started
```bash
npm install
npm run dev
```
